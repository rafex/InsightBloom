# Assistant

Assistant se distribuye como fuente local del producto mediante `@font-face` en
`src/styles/global.css`.

Los archivos WOFF2 provienen de la copia de Assistant incluida por la dependencia
`@excalidraw/excalidraw` ya declarada en `package.json`. Assistant es una fuente de Google
Fonts distribuida bajo SIL Open Font License 1.1; conservar esta referencia junto a los
binarios si se actualiza la fuente.
