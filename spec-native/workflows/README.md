# workflows/

Procedimientos operativos para el ciclo de vida de iniciativas.

## Documentos

| Archivo | Propósito |
|---------|-----------|
| [`PLANNING.md`](./PLANNING.md) | Cómo planificar iniciativas — de problema a spec y tareas |
| [`IMPLEMENTATION.md`](./IMPLEMENTATION.md) | Cómo implementar tareas — flujo completo por lenguaje |
| [`REVIEW.md`](./REVIEW.md) | Cómo revisar implementación contra spec |

## Flujo completo

```
PRODUCT.md → ROADMAP.md → SPEC.md → TASKS.md → IMPLEMENTACIÓN → REVIEW → CI/CD
```

Cada etapa tiene su workflow documentado. Sigue el orden y respeta los gates.
