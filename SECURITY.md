# Security policy

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** option on the [InsightBloom Security tab](https://github.com/rafex/InsightBloom/security). Private vulnerability reporting is enabled for this repository. If the option is missing, do not post details publicly; contact the repository owner through GitHub and ask for a private reporting channel.

Do not report security vulnerabilities through public GitHub issues, pull requests, or the organizer support form. Do not include attendee personal data, access tokens, passwords, or production secrets. A concise description, affected component/version, impact, and safe reproduction notes are enough. Do not test against production or access data that is not yours.

## Supported versions

Security fixes are made for the latest `main` branch. No older release branch is currently designated as supported.

## Response

Reports are reviewed by the project owner. The project does not promise a public response or remediation SLA. Coordinated disclosure and any public advisory will be handled after impact is understood and a fix or mitigation is available.
